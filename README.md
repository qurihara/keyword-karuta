# 百人一首キーワード取り（keyword-karuta）

百人一首の歌の中から、7つのキーワード（四季・自然・感情・朝と夜・天候・生き物・地名）に
当てはまる語を探して取り合うゲームの試作である。

ブラウザだけで遊べる。 → **https://unryu.org/keyword-karuta/**

## これは何か

公益財団法人 中山隼雄科学技術文化財団の「社会を変える『夢のゲーム』研究アイディア大募集」
2025年度 優秀賞「百人一首を活用して 言葉と文化にふれるゲーム」（増村賢二さん）を、
どう実現できるかを検討するために作った試作である。
2027年度 調査研究への応募にむけた検討の一部であり、財団の採択を受けたものではない。

## 遊び方

読み札を1枚めくって場に出す。手札のキーワード札を1枚出し、その根拠になる語を歌の中から指す。
たとえば「四季」の札なら「秋」を指す。当たっていればキーワードの得点を得て、その和歌札を取る。
外れればお手つきで、その回から降りる。山札が尽きたら終わり、合計点の多い人が勝ち。

得点は　四季1点／自然2点／感情3点／朝と夜4点／天候5点／生き物6点／地名7点。
四季1点と地名7点は入賞アイディアの記述に従い、間の5つは暫定である。

### 決着の付け方を2つ切り替えられる

- **C　順番に競り上げる**　前の回の勝者が最初に出し、以後は時計回り。いま出ている札より高い札を
  出すか、降りるかを選ぶ。全員が降りたら最後に出した人が取る。
  出すたびに語を指すので、後の人は前の人の発見を見て学べる。
- **B　同時公開の競り**　読み上げが終わるまでに全員が伏せて1枚を出し、同時に公開する。
  同じキーワードが複数出たら、それらはすべて無効になる（相殺）。残ったうち最も高い札を出した人が取る。
  高い札を出したほうが競り負ける、という読み合いが生まれる。

どちらが誰に向くかを調べること自体が、この検討の問いである。

## 中身

| ファイル | 中身 |
|---|---|
| `index.html` | ゲーム本体。サーバ側の処理は無く、静的なファイルだけで動く |
| `data.js` | 20首の本文、語の区切り、語とキーワードの対応、現代語訳 |
| `sounds/` | 読み上げ音声（VOICEVOXによる合成。上の句がA、下の句がB） |
| `yomi.json` / `make_yomi.py` | 読み仮名と、音声を作り直すための手順 |

## 読み上げの音声について

読み札の読み上げを「考える時間の物差し」として使う。砂時計のような人工的な制限ではなく、
和歌そのものが締切を作る。

音声は VOICEVOX による合成で、読みの速さは1モーラあたり200ミリ秒を目安にした。
上の句が約3.9秒、下の句が約3.3秒である。競技かるたの読手のような節回しは出ないが、
時間の物差しとしては足りる。

`yomi.json` に読み仮名を、`make_yomi.py` に合成の手順を置いてある。
VOICEVOX を起動して `python3 make_yomi.py` を実行すると作り直せる。
`MORA_SEC` を変えれば速さを変えられる。

音声ファイルが無い場合は、決まった秒数の砂時計で代用する。遊びの骨格は変わらない。

## 出典

- 歌の本文と現代語訳は [qurihara/alt_hyakunin_isshu](https://github.com/qurihara/alt_hyakunin_isshu) の
  `data.csv` による。同リポジトリによれば、和歌の一般的な解釈は全日本かるた協会ウェブサイトからの引用である。
- 語の区切りと、語とキーワードの対応は、この検討で新たに付けたものである。暫定であり、
  「露は自然か天候か」のような曖昧さをどう扱うかは、検討すべき課題として残っている。
- 辞書に無い語を指したときは「不正解」とせず、判定できないものとして扱う方針である。
